## 🚀 Featured Projects

### 1. [City App — Hyperlocal Marketplace](https://github.com/Mu-za-mil/city-app)

**Java 21 · Spring Boot · PostgreSQL · Redis · Kafka · Docker · Kubernetes**

A backend platform concept connecting local commerce and community services. The project explores service decomposition, event-driven workflows, security, reliability, and operating a distributed application.

- Evolved a modular-monolith backend toward independently deployable services using the **Strangler Fig** approach.
- Built service boundaries around gateway, authentication, main backend, notification, and service discovery.
- Designed Kafka-based event flows and explored the **Saga pattern** for distributed transaction consistency.
- Built an observability stack with Prometheus, Grafana dashboards, centralized logging through Loki/Promtail, and distributed tracing with Zipkin.
- Created Docker-based development workflows, GitHub Actions CI, Kubernetes manifests, and Helm-related deployment assets; validating the deployment path incrementally.

> See the repository for the current implementation and deployment status.
